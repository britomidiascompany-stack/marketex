Como adicionar o MCP do VKmetrics nas IAs

Conecte Claude, ChatGPT, Cursor, Windsurf ou Codex ao VKmetrics e acesse dados de campanhas, funis e vendas direto na conversa. Escolha sua ferramenta abaixo e siga o passo a passo completo.

URL do servidor MCP
https://bi.vkdigital.com.br/ai/metrics-mcp
Passo a passo

Selecione sua ferramenta

Escolha abaixo a IA que voce usa. O guia mostra cada clique necessario, do zero ate o servidor conectado.

1

Acesse o Claude.ai

Abra o navegador e va para claude.ai. Faca login na sua conta.

2

Abra as Configuracoes

No canto inferior esquerdo, clique no seu nome ou avatar. No menu que abre, clique em Configuracoes (ou Settings).

3

Va na aba Conectores

Dentro das configuracoes, clique na aba Conectores (pode aparecer como "Integrations" dependendo do idioma).

Configuracoes › Conectores
4

Clique em Novo conector

Clique no botao Novo conector (ou "Add connector" / "+ New").

5

Preencha o nome e a URL

No campo de nome, escreva VKmetrics. No campo de URL do servidor MCP, cole o endereco abaixo:

URL do servidor MCP
https://bi.vkdigital.com.br/ai/metrics-mcp
6

Clique em Salvar

Clique em Salvar. O conector aparece na lista e fica ativo automaticamente em todas as conversas.

✓

Pronto! Abra uma nova conversa e pergunte: "Quais campanhas do Meta estao ativas agora?" O Claude consulta o VKmetrics e responde com os dados reais.

1

Abra o terminal

Escolha seu sistema abaixo:

Pressione Cmd + Espaco para abrir o Spotlight. Digite Terminal e pressione Enter.

Ou va em: Finder → Aplicativos → Utilitarios → Terminal

Pressione Win + R, digite cmd e pressione Enter.

Ou clique no menu Iniciar, procure por PowerShell ou Terminal do Windows e abra.

2

Execute o comando de adicao do MCP

Cole o comando abaixo no terminal e pressione Enter:

bash — terminal (Mac ou Windows)
claude mcp add --transport http "VKmetrics" https://bi.vkdigital.com.br/ai/metrics-mcp

Se aparecer uma mensagem de confirmacao, pressione Enter ou Y para confirmar.

3

Confirme que funcionou

Rode o comando abaixo para ver a lista de servidores ativos:

bash
claude mcp list

O VKmetrics deve aparecer na lista com status ativo.

4

Alternativa: configurar pelo arquivo JSON

Se preferir adicionar manualmente, abra o arquivo de configuracao do Claude Code:

Arquivo: ~/.claude/settings.json

Arquivo: %APPDATA%\Claude\settings.json

Adicione o bloco abaixo dentro do arquivo (se ja tiver outros campos, coloque so o bloco mcpServers dentro do objeto existente):

json — settings.json
{
  "mcpServers": {
    "VKmetrics": {
      "type": "http",
      "url": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
✓

Pronto! O Claude Code ja consulta o VKmetrics nas proximas sessoes.

⚠

Plano necessario: MCP no ChatGPT exige plano Pro, Team, Enterprise ou Edu. Nao funciona no plano gratuito. Faca isso pelo navegador — nao funciona no app mobile.

1

Acesse o ChatGPT pelo navegador

Abra chat.openai.com e faca login com sua conta Pro, Team, Business ou Enterprise.

2

Abra as Configuracoes

Clique no seu nome ou avatar no canto inferior esquerdo da tela. No menu que aparece, clique em Configuracoes (Settings).

3

Ative o Modo de Desenvolvedor (Developer Mode)

Dentro das configuracoes, navegue pelo caminho abaixo:

Configuracoes › Apps › Configuracoes avancadas › Modo de desenvolvedor

Ative a chave Developer Mode. Sem isso, a opcao de adicionar MCP nao aparece.

ℹ

Business/Enterprise: so administradores e donos do workspace conseguem ativar. O caminho pode variar ligeiramente: Workspace → Configuracoes → Apps → Criar ou Configuracoes → Apps → Configuracoes avancadas → Modo de desenvolvedor.

4

Va em Apps e adicione o servidor

Com o Developer Mode ativo, va em:

Configuracoes › Apps

Clique em Criar ou Adicionar app. Escolha a opcao de MCP / servidor externo.

5

Preencha o nome e a URL

Coloque o nome VKmetrics e selecione o transporte Streamable HTTP. Cole a URL abaixo no campo de endereco do servidor:

URL do servidor MCP
https://bi.vkdigital.com.br/ai/metrics-mcp
6

Salve e teste

Clique em Salvar. Abra uma nova conversa no ChatGPT e pergunte algo sobre as campanhas para confirmar que o VKmetrics esta conectado.

✓

Pronto! O ChatGPT vai consultar os dados do VKmetrics automaticamente quando voce perguntar sobre campanhas, funis ou vendas.

ℹ

Plano Pro: ferramentas de leitura e busca funcionam completamente. Ferramentas que modificam dados exigem Business ou Enterprise.

1

Abra o terminal

Escolha seu sistema:

Pressione Cmd + Espaco, digite Terminal e pressione Enter.

Ou: Finder → Aplicativos → Utilitarios → Terminal

Pressione Win + R, digite cmd e pressione Enter.

Ou clique em Iniciar, procure PowerShell e abra.

2

Instale o Codex CLI (se ainda nao tiver)

Rode o comando abaixo para instalar. Se ja tiver instalado, pule para o passo 3.

bash
npm install -g @openai/codex
3

Adicione o servidor VKmetrics

Cole o comando abaixo e pressione Enter:

bash
codex mcp add VKmetrics --url https://bi.vkdigital.com.br/ai/metrics-mcp
4

Confirme que foi adicionado

bash
codex mcp list

O VKmetrics deve aparecer na lista.

5

Alternativa: editar o arquivo de configuracao

Se preferir, edite o arquivo ~/.codex/config.toml diretamente e adicione:

toml — ~/.codex/config.toml
[mcp_servers.VKmetrics]
transport = "http"
url       = "https://bi.vkdigital.com.br/ai/metrics-mcp"
✓

Pronto! O Codex ja usa o VKmetrics nas sessoes seguintes.

1

Abra as configuracoes do Cursor

Dentro do Cursor, pressione o atalho:

Pressione Cmd + Shift + J para abrir as configuracoes do Cursor diretamente.

Pressione Ctrl + Shift + J para abrir as configuracoes do Cursor diretamente.

2

Va em MCP

Dentro das configuracoes, clique na aba MCP ou pesquise "MCP" no campo de busca.

Settings › Features › MCP
3

Abra o arquivo de configuracao

Clique em Edit MCP Settings (ou "Open Config"). O arquivo ~/.cursor/mcp.json vai abrir no editor.

4

Adicione o VKmetrics no arquivo

Substitua o conteudo do arquivo pelo bloco abaixo. Se ja tiver outros servidores, adicione so o bloco "VKmetrics" dentro de mcpServers, separado por virgula:

json — ~/.cursor/mcp.json
{
  "mcpServers": {
    "VKmetrics": {
      "url": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
5

Salve e reinicie o Cursor

Salve o arquivo (Cmd+S no Mac / Ctrl+S no Windows). Feche e abra o Cursor novamente. O VKmetrics vai aparecer na lista de ferramentas MCP ativas.

✓

Pronto! O VKmetrics esta disponivel no painel MCP do Cursor.

1

Abra as configuracoes do Windsurf

Pressione o atalho:

Pressione Cmd + , (virgula) para abrir as configuracoes.

Pressione Ctrl + , (virgula) para abrir as configuracoes.

2

Encontre a secao de MCP

Dentro das configuracoes, procure por MCP ou Cascade. Clique em Open Config para abrir o arquivo de configuracao.

Settings › Cascade › MCP Servers › Open Config
3

Adicione o VKmetrics no arquivo

O arquivo que abre e o ~/.codeium/windsurf/mcp_config.json. Adicione o bloco abaixo (se ja tiver outros servidores, inclua o bloco "VKmetrics" dentro de mcpServers, separado por virgula):

json — mcp_config.json
{
  "mcpServers": {
    "VKmetrics": {
      "serverUrl": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
4

Salve e reinicie o Windsurf

Salve o arquivo e feche e abra o Windsurf. O servidor VKmetrics vai aparecer disponivel no painel do Cascade.

✓

Pronto! Pergunte ao Cascade "Quais campanhas estao ativas?" e ele consulta o VKmetrics automaticamente.

O que e o MCP

Por que conectar a IA ao VKmetrics?

O MCP (Model Context Protocol) permite que a IA acesse dados externos em tempo real. Com o VKmetrics conectado, voce pergunta e ela responde com os numeros reais das campanhas.

📊

Dados em tempo real

A IA acessa as metricas atualizadas diretamente, sem exportar planilhas.

🤖

Analises instantaneas

Peca comparativos, tendencias e insights direto na conversa.

⚡

Configure uma vez

O servidor fica ativo em todas as conversas automaticamente.

Como adicionar o MCP do VKmetrics nas IAs

Conecte sua IA ao VKmetrics via MCP e acesse dados de campanhas, funis e vendas direto na conversa. Funciona com Claude, Cursor, Windsurf e outras ferramentas compatíveis.

URL do servidor MCP
https://bi.vkdigital.com.br/ai/metrics-mcp
Passo a passo

Selecione sua ferramenta

O processo varia conforme a IA que você usa. Escolha abaixo e siga as instruções da sua ferramenta.

1

Acesse as configurações do Claude.ai

Abra o claude.ai no navegador. Clique no seu avatar ou no menu no canto inferior esquerdo e vá em Configurações.

2

Abra a aba de Conectores

Dentro das configurações, clique na aba "Conectores" (ou "Integrations"/"MCP", dependendo da versão do idioma).

Configurações › Conectores
3

Adicione um novo conector

Clique em "Novo conector" ou "Add connector".

4

Preencha o nome e a URL

Dê o nome VKmetrics e cole a URL abaixo no campo do MCP:

URL do servidor
https://bi.vkdigital.com.br/ai/metrics-mcp
5

Salve e confirme

Clique em Salvar. O conector vai aparecer na lista e vai ficar ativo para todas as conversas do Claude.ai automaticamente.

✓

Pronto! Para testar, abra uma nova conversa e pergunte algo como: "Quais campanhas do Meta estão ativas agora?" — o Claude vai consultar os dados diretamente do VKmetrics.

1

Abra o terminal

Qualquer terminal funciona: Terminal do Mac, iTerm, ou o terminal integrado no VS Code.

2

Execute o comando de adição

Cole o comando abaixo e pressione Enter:

bash — terminal
claude mcp add --transport http "VKmetrics" https://bi.vkdigital.com.br/ai/metrics-mcp
3

Confirme o servidor adicionado

Para verificar se funcionou, rode:

bash — terminal
claude mcp list

O VKmetrics deve aparecer na lista de servidores ativos.

4

Alternativa: editar o settings.json

Se preferir adicionar manualmente, abra o arquivo ~/.claude/settings.json e adicione:

json — ~/.claude/settings.json
{
  "mcpServers": {
    "VKmetrics": {
      "type": "http",
      "url": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
ℹ

Se o settings.json ja tiver outros campos, adicione só o bloco "mcpServers" dentro do objeto existente, sem apagar o que ja está lá.

1

Abra as configurações do Cursor

No Cursor, abra o menu de configurações. Você pode usar o atalho Cmd + Shift + J (Mac) ou Ctrl + Shift + J (Windows) para abrir o painel de configurações do Cursor.

2

Vá em MCP

Dentro das configurações do Cursor, clique na aba "MCP" ou procure por "MCP" no campo de busca das configurações.

Settings › Features › MCP
3

Edite o arquivo mcp.json

Clique em "Edit MCP Settings" ou abra o arquivo diretamente em ~/.cursor/mcp.json. Adicione o bloco do VKmetrics:

json — ~/.cursor/mcp.json
{
  "mcpServers": {
    "VKmetrics": {
      "url": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
ℹ

Se o arquivo ja tiver outros servidores dentro de "mcpServers", adicione o bloco "VKmetrics" ao lado dos que ja existem, separado por vírgula.

4

Salve e reinicie o Cursor

Salve o arquivo. O Cursor vai carregar o servidor automaticamente. Se não aparecer de imediato, feche e abra o Cursor novamente.

✓

Pronto! O VKmetrics vai aparecer na lista de ferramentas disponíveis no painel MCP do Cursor.

1

Abra as configurações do Windsurf

No Windsurf, acesse o menu superior e vá em Windsurf → Settings, ou use o atalho Cmd + , (Mac) / Ctrl + , (Windows).

2

Encontre a seção de MCP

No painel de configurações, procure por "MCP" ou "Model Context Protocol". Clique em "Open Config" para abrir o arquivo de configuração.

Settings › Cascade › MCP Servers › Open Config
3

Adicione o VKmetrics no arquivo de configuração

O arquivo que vai abrir é o ~/.codeium/windsurf/mcp_config.json. Adicione o bloco abaixo:

json — mcp_config.json
{
  "mcpServers": {
    "VKmetrics": {
      "serverUrl": "https://bi.vkdigital.com.br/ai/metrics-mcp"
    }
  }
}
ℹ

Se o arquivo ja tiver outros servidores, adicione "VKmetrics" dentro do objeto "mcpServers" existente, separado por vírgula.

4

Salve e reinicie o Windsurf

Salve o arquivo e reinicie o Windsurf. O servidor VKmetrics vai aparecer disponível no painel do Cascade.

✓

Pronto! Pergunte para o Cascade: "Quais campanhas estão rodando no Meta?" e ele vai consultar o VKmetrics automaticamente.

O que é o MCP

Por que conectar a IA ao VKmetrics?

O MCP (Model Context Protocol) é um protocolo que permite que ferramentas de IA acessem dados externos em tempo real. Com o VKmetrics conectado, a IA pode consultar métricas de campanhas, vendas e funis diretamente na conversa, sem precisar copiar e colar planilhas.

📊

Dados em tempo real

A IA acessa as métricas atualizadas direto no VKmetrics, sem depender de exportações manuais.

🤖

Análises automáticas

Peça análises, comparativos e insights diretamente na conversa com a IA, sem abrir o painel.

⚡

Uma configuração, sempre ativo

Configure uma vez e o servidor fica disponível em todas as conversas da ferramenta automaticamente.

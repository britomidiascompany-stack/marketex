Instalar o GTM na página da Lovable

Passo a passo para colocar o Google Tag Manager na nova página do LS. Basta colar um prompt na Lovable: o GTM já está configurado e publicado com pixel, servidor, GA4, VK e repasse de UTMs.

ls.lucrocomia.com.brGTM-MXCRT4LMFeito na Lovable
Passo 1

Cole este prompt na Lovable

Abra o projeto da página na Lovable, cole o texto abaixo no chat e envie. Ele instala o GTM do jeito certo e publica no domínio.

Prompt para a Lovable
Instale o Google Tag Manager (GTM-MXCRT4LM) neste projeto, seguindo exatamente estas regras:

1. No arquivo index.html (raiz do projeto), cole o código abaixo O MAIS ALTO POSSÍVEL dentro do <head>, logo depois da tag <meta charset>:

<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-MXCRT4LM');</script>
<!-- End Google Tag Manager -->

2. No mesmo index.html, cole o código abaixo IMEDIATAMENTE depois da abertura da tag <body>:

<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-MXCRT4LM"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->

3. NÃO adicione nenhum outro código de rastreamento direto no projeto (nada de Meta Pixel / fbq, Google Analytics / gtag, VK Metrics, Clarity ou similares). Tudo isso já é disparado pelo GTM. Se já existir algum desses códigos no projeto, remova.

4. Todos os botões de compra que levam para o checkout da Hotmart (https://pay.hotmart.com/...) devem ser links <a href="https://pay.hotmart.com/..."> normais. Não use window.location, navigate() ou onClick com JavaScript para abrir o checkout, e não abra em nova aba. Isso é necessário para o GTM repassar as UTMs para a Hotmart.

5. Não remova nem reescreva os parâmetros da URL (utm_source, utm_medium, utm_campaign, utm_content, utm_term, src, sck, vk_source, fbclid) ao carregar a página ou trocar de rota.

6. Não altere nada no visual nem no conteúdo da página. Depois de aplicar, publique o projeto no domínio ls.lucrocomia.com.br.
Por que os botões precisam ser links normais? O GTM acrescenta as UTMs, o src e o vk_source no link da Hotmart na hora do clique. Se o botão abrir o checkout por JavaScript, os parâmetros se perdem e a venda fica sem campanha.
